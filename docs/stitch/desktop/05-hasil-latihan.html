Hasil dari 2³ × 2⁴ adalah ...

done Jawabanmu: A (2⁷)
menu_book Pembahasan Langkah demi Langkah:
  1. Sifat perkalian bilangan berpangkat dengan basis sama: aᵐ × aⁿ = aᵐ⁺ⁿ
  2. Maka, 2³ × 2⁴ = 2³⁺⁴ = 2⁷
  3. Jadi hasil yang benar adalah A.

Bentuk paling sederhana dari (a³b²) / (ab) adalah ...

close Jawabanmu: B (ab²)
check Kunci: C (a²b)
menu_book Pembahasan Langkah demi Langkah:
  1. Gunakan sifat pembagian pangkat: aᵐ / aⁿ = aᵐ⁻ⁿ
  2. Untuk a: a³ / a¹ = a³⁻¹ = a²
  3. Untuk b: b² / b¹ = b²⁻¹ = b¹ = b
  4. Maka hasilnya adalah a²b (Pilihan C).

Nilai dari 4⁻² sama dengan ...

done Jawabanmu: C (1/16)
menu_book Pembahasan Langkah demi Langkah:
  1. Sifat pangkat negatif: a⁻ⁿ = 1 / aⁿ
  2. Maka, 4⁻² = 1 / 4² = 1 / 16
  3. Jawaban benar adalah C.

done Jawabanmu: B (3⁶)
menu_book Pembahasan Langkah demi Langkah:
  1. Sifat pemangkatan bilangan berpangkat: (aᵐ)ⁿ = aᵐˣⁿ
  2. Maka, (3²)³ = 3²ˣ³ = 3⁶
  3. Jawaban benar adalah B.

Bentuk baku dari 0,00025 adalah ...

done Jawabanmu: D (2,5 × 10⁻⁴)
menu_book Pembahasan Langkah demi Langkah:
  1. Bentuk baku dinyatakan sebagai a × 10ⁿ dengan 1 ≤ a < 10.
  2. Geser koma 4 langkah ke kanan: 2,5.
  3. Karena digeser ke kanan, pangkat bernilai negatif: 10⁻⁴.
  4. Jadi hasilnya 2,5 × 10⁻⁴.
