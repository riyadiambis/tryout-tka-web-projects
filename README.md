# Web Tryout TKA SD & SMP

Aplikasi Web Tryout Tes Kemampuan Akademik (TKA) untuk jenjang SD dan SMP.

## Tech Stack
- **Runtime**: Bun
- **Framework**: ElysiaJS
- **ORM**: Drizzle ORM
- **Database**: MySQL
- **Containerization**: Docker Compose
